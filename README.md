# Smart Quiz Master

Концепция

Название:ZhanQuiz Суть: Одностраничный сайт-квиз с двумя режимами — английский язык (слова) и математика. Пользователь выбирает тему, отвечает на вопросы по одному, в конце видит результат и разбор ошибок.

Структура сайта

Стартовый экран

Заголовок, короткое описание

Кнопки выбора: "Английский" / "Математика" / "Смешанный режим" (оба вместе)

Выбор количества вопросов (например 10/20/все)

Экран вопроса

Прогресс-бар (вопрос 5 из 20)

Таймер на вопрос (по желанию — можно убрать, если не нужно)

Сам вопрос + варианты ответа (или поле ввода — зависит от типа)

Кнопка "Далее"

Экран результатов

Итоговый счёт (например 17/20)

Разбор: какие вопросы ответил неправильно и правильный ответ

Кнопка "Пройти ещё раз"

Типы вопросов

Английский:

Перевод слова (RU→EN или EN→RU), варианты ответа

Можно добавить: "выбери правильную форму глагола", синонимы/антонимы

Математика:

Примеры на вычисление (арифметика, можно посложнее — уравнения, проценты)

Можно генерировать примеры автоматически (случайные числа), а не хранить готовый список — тогда квиз каждый раз разный

Дизайн 

Приятная цветовая палитра (не дефолтный шаблон — что-то со своим характером, например тёмный фон с акцентным цветом или наоборот светлый и чистый)

Анимация при переходе между вопросами

Разные цвета/иконки для английского и математики, чтобы визуально отличать режимы

Адаптивность под телефон

 Технические фичи (для впечатления преподавателя)

Сохранение прогресса/рекорда в localStorage (лучший результат)

Случайная генерация вопросов по математике (не захардкожено)

Звук/анимация при правильном/неправильном ответе (по желанию)

Статистика по итогу: сколько правильных по английскому, сколько по математике отдельно

Что можно добавить от себя:

Уровни сложности (лёгкий/средний/сложный)

Ограничение по времени на весь квиз

Таблицу лидеров (если несколько человек проходят на одном устройстве)

Свои конкретные слова/примеры, если хочешь конкретный список, а не случайную генерацию
